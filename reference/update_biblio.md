# Function to update the biblio metadata file

This function updates the biblio metadata file with the values from the
DESCRIPTION file, along with some standard templated values for funder,
license, etc.

## Usage

``` r
update_biblio()
```

## Value

NULL. Throws an error if DESCRIPTION does not exist.

## Examples

``` r
if (FALSE) { # \dontrun{
update_biblio()
} # }
```
