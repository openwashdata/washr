# Updates the access metadata file with links to the downloadable data files

This function updates the access metadata file with the links to the
downloadable data files in xlsx and csv format. Redirects to the github
repo raw download links. Meant to be a util function for the
`update_metadata` function.

## Usage

``` r
update_access()
```

## Value

NULL.

## Examples

``` r
if (FALSE) { # \dontrun{
update_access()
} # }
```
