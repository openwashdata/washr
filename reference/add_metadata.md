# Adds metadata files and creates the metadata folder

Creates the data/metadata directory with the acess, attributes, biblio
and creators metadata files. If the directory already exists, the user
is prompted to overwrite the existing files.

## Usage

``` r
add_metadata()
```

## Value

NULL. Error message if the metadata folder already exists and user
declines to create new metadata files.

## Examples

``` r
if (FALSE) { # \dontrun{
add_metadata()
} # }
```
